# My First API

A simple REST API built with Node.js and Express.

## Tech Stack

- Node.js
- Express

## Getting Started

### Prerequisites

- Node.js installed

### Installation

1. Clone the repository
   git clone https://github.com/Assuredevops/my-first-api.git

2. Install dependencies
   npm install

3. Start the server
   node index.js

4. Visit http://localhost:3000

## API Routes

| Method | Route      | Description             |
| ------ | ---------- | ----------------------- |
| GET    | /          | Welcome message         |
| GET    | /users     | Get all users           |
| GET    | /users/:id | Get a single user by ID |
